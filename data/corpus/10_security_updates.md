# 安全、密钥与知识更新

API Key 只能通过环境变量或密钥管理服务注入，仓库只提交 .env.example 占位符。提交前要扫描 .env、私钥、令牌格式、真实数据库和日志。疑似密钥一旦进入公开历史，应先撤销或轮换，而不只是删除当前文件。

知识库更新需要稳定 document_id 和 chunk_id。重复入库会制造重复证据；删除文档时要同步删除向量索引、关键词索引和图关系。索引版本应记录语料哈希、切分参数与 Embedding 版本，防止服务读取不兼容的旧索引。

来自文档的 Prompt Injection 不能被当作系统指令执行。生产系统要隔离系统提示与检索内容，并结合权限过滤、来源白名单、内容审计和最小化工具权限。
